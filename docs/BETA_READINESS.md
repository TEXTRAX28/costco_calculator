# Gather beta readiness

## Data flow

| Data | Processing | Storage and controls |
| --- | --- | --- |
| Original photo, camera frame, PDF and pasted text | The browser validates imports and prepares scans. The PDF is rendered locally. Camera tracks stop after capture, close or backgrounding. | The active browser tab holds previews and source text. Clear local data releases them. A relaunch restores the saved draft and requires the user to select the source images again. |
| Prepared JPEG sections and model output | A scan sends JPEG sections and section positions to the app server, which sends them to the OpenAI Responses API. The server buffers and validates the request and result in memory. | The app code has no upload files, response store or receipt-content log. A browser can save the returned editable draft. Provider logs, caching and transfer are governed by the API account and its terms. |
| Editable receipt, participant names and shares | The browser reconciles amounts and calculates the split. The scan payload contains images and section positions. Names entered for splitting are used locally. | One draft per browser profile and origin in localStorage, until cleared, replaced, or removed by the browser. Other open tabs can retain an in-memory copy. Exported files and clipboard copies persist at their destinations. |
| Allowance and access | The server reserves an exclusive numbered slot before the provider request and records ID, time and outcome. The paired preview keeps login attempts and session IDs in memory and sets an eight-hour session cookie. A protected proxy receives the client IP and handles sign-in. | Keep the allowance directory private and persistent so restarting the beta keeps its count. The included proxy template leaves access logging off. The chosen host may collect operational or network logs. Verify its actual log fields, retention and support access before inviting testers. |
| Installed app | The service worker precaches versioned program files, icons and the app shell from the same origin. | API responses, request bodies, pairing responses, exports and private data stay outside the service worker cache. The browser’s site settings control the static cache and session. |

The app uses `store: false` in Responses requests. OpenAI says API data is excluded from model training by default unless the account opts in. Default abuse-monitoring records can include content and typically last up to 30 days, subject to documented exceptions. Caching and service processing also need to be checked against the actual project configuration and terms. [OpenAI API data controls](https://developers.openai.com/api/docs/guides/your-data)

The app asks for affirmative permission before each upload and credit use. The operator must decide and document the applicable UK GDPR basis separately. The local draft, preview cookie and app-shell cache are browser storage technologies. Document their purposes and assess the applicable PECR conditions for the intended beta. [ICO privacy notice requirements](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/individual-rights/the-right-to-be-informed/what-privacy-information-should-we-provide/) · [ICO storage exceptions](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/what-are-the-exceptions/)

## Protected hosting

The [Caddy file](../hosting/Caddyfile.example) is a template for a small invited beta. Use a dedicated HTTPS hostname and Caddy 2.11 or newer on the same host as the loopback Node server. Set `GATHER_BETA_SITE` to the HTTPS site address and `GATHER_BETA_ORIGIN` to its exact browser origin, without a trailing slash. Supply `GATHER_BETA_USER` and a bcrypt hash in `GATHER_BETA_PASSWORD_HASH` from the hosting secret store. Generate it interactively with `caddy hash-password`. Validate with `caddy validate --adapter caddyfile --config hosting/Caddyfile.example` in the configured environment. Keep port 4175 private. The [Oracle setup](ORACLE_FREE_BETA.md) uses the same proxy protections with HTTPS on the VM's public IP.

The HTTPS gateway authenticates all paths, including scan status and install assets. It checks the original POST origin before adapting the request to the Node loopback API, strips credentials upstream, and enforces the existing upload byte limit. Keep real provider credentials in the Gather server only. Start the built app with `npm start` as a restricted service user. Use a persistent volume for `OPENAI_ALLOWANCE_DIRECTORY`, the same `OPENAI_ALLOWANCE_ID` across restarts and an intentional `OPENAI_REQUEST_LIMIT`. Use one server process for the rolling request limits. Host the app at the origin root so installation and API paths agree.

Use a dedicated beta OpenAI project if the owner sets up hosting. Verify its model access, sharing settings and spend alerts. The app guard remains a US$3 estimate per request. The attempt counter advances at reservation, including a later failure or cancellation, and blocks new submissions when the allowance runs out. OpenAI bills usage under the configured project. [GPT-6 Astra pricing](https://developers.openai.com/api/docs/models/gpt-6-astra)

## Before inviting testers

The in-app notices describe the local and invited build. For hosted use, supply the actual controller or operator name and contact, the route for privacy requests, and the agreed purpose, lawful basis, retention and recipients. Verify the hosting and OpenAI terms, processor arrangements where applicable, project data settings and any relevant transfer safeguards. Check the applicable website disclosures and approve the notices using the confirmed facts. [ICO international transfers guidance](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/international-transfers/a-guide-to-international-transfers/) · [UK service information requirements](https://www.legislation.gov.uk/uksi/2002/2013/regulation/6)

On a physical iPhone, open trusted HTTPS in Safari, install with Add to Home Screen and launch from the icon. Check safe areas in both orientations, VoiceOver navigation, and whether Continue reveals and focuses an invalid value with the software keyboard open. Try the camera with permission enabled and denied. Switch apps mid-camera and mid-scan, return, and check recovery and the recorded allowance. Reopen an edited draft online and in airplane mode after one successful online launch. Check the update across two builds, including close and relaunch from the Home Screen and re-entry to a protected session when prompted. Confirm exports and Clear local data in the installed app. [Apple’s iPhone guide](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27)

Use synthetic receipts during local testing. The real Costco result supplied by the user was 18 purchases, a £2.00 skewer coupon, £13.62 VAT and £176.78 paid. Compare those values and the exported split if the owner chooses to run a live scan in the hosted beta. Check quantities on the restaurant receipt and confirm the two ramen bowls show £18.60 each and £37.20 in total.

The PWA uses browser installation. A native App Store release or in-app payments would be a separate scope.
